How to use Merge PDF

  1. Keep an original copy, then select the files using the button above.
  2. Follow any options shown by the tool and wait for processing to finish.
  3. Download the output and review it before sharing or replacing your original.

What to expect

Combines two or more PDFs in the order selected by your file picker. Password-protected files may need to be unlocked in another application first. Very large files can exceed your device’s available memory; try a smaller document if processing fails.

Privacy and troubleshooting

Your document is processed locally. If a dependency fails to load, reload the page with a working internet connection. If a text export is empty, the source may be scanned rather than text-based.
